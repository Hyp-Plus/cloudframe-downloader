# 权利人通知与处理规则

最后更新：2026 年 8 月 19 日

云帧下载器不提供内容托管、云端分发或内容索引服务；下载文件和任务通常仅在用户本机处理。本项目仍重视权利人对软件功能、宣传材料、源代码或发布物提出的合理通知。

## 提交通知

请通过项目 [Issues](https://github.com/Hyp-Plus/cloudframe-downloader/issues) 提交通知，并尽量包含：

1. 你的姓名或机构名称及可回复的联系方法；
2. 你主张的权利与授权依据；
3. 涉及的具体页面、仓库文件、发布版本、宣传物料或复现步骤；
4. 你认为存在的问题与希望采取的处理措施；
5. 你确认所述信息真实、完整的声明。

请勿在公开 Issue 中提交 Cookie、密码、身份证件原件、银行卡信息或其他敏感资料。若需要补充非公开材料，可先在 Issue 中说明需要私下联系。

## 处理原则

收到信息完整的通知后，项目维护者将基于已提供材料评估是否需要澄清宣传、修订文档、移除争议资产、限制相关发布物或采取其他合理措施。项目维护者不对第三方平台、用户设备或用户本地文件拥有控制权；对于用户本地行为，权利人可同时向有关用户、平台或主管机关主张权利。

本规则不构成对任何争议事实、责任归属、侵权成立或补偿义务的承认，也不限制任何一方依法享有的权利。
