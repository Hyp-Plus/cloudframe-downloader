# 云帧下载器

一个面向个人授权内容保存的 macOS / Windows 桌面应用。

**云帧下载器 v1.0.0 · 铃铛出品**

## 已实现

- 品牌化 Electron + React 桌面界面
- 哔哩哔哩、抖音、YouTube、Instagram、小红书、X / Twitter 的公开链接识别与下载队列
- 下载画质、保存目录、实时进度与错误状态
- 受限 Electron IPC：页面只能请求选目录与新建下载任务
- 工业输送线任务视图：任务舱随解析、下载、转码、入库进度移动
- 失败任务可重试，并对代理/证书校验错误给出明确提示

## 运行

```bash
npm install
npm run dev
```

在 macOS 上，以上平台的公开媒体下载需要安装 `yt-dlp` 与 `ffmpeg`：

```bash
brew install yt-dlp ffmpeg
```

构建前端与 Electron 主进程：

```bash
npm run build
```

## 视频号状态

视频号下载模块已从当前版本静默，不会启动任何连接器、安装证书或修改系统代理。后续仅会在具备不影响系统网络且允许合法分发的实现方案时重新评估。

该组件将要求显式同意、清晰展示本机证书/代理状态、退出时关闭代理并提供证书移除。它不处理私密、付费、DRM 或绕过访问控制的内容。
